# KAHE Attendance app

Mobile and browser attendance app for students and faculty.

- [Download the Android app](https://kahe-attendance-download.vercel.app)
- [Open the browser app](https://kahe-attendance.vercel.app)
- [Release notes and APKs](https://github.com/PradFr/attend-app/releases)

Current Android release: **1.0.6**, version code **7**, for Android 7.0+ on 32-bit and 64-bit ARM devices.

The app source is in `KAHE-mobile-attendance-frontend-api/`. The download website is in `download-page/`, and `src/types/` contains shared TypeScript contracts.

Build updates with the existing signing identity so installed copies can update without being uninstalled.
